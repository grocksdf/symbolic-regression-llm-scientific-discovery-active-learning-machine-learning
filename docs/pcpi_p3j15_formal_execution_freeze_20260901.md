# P3J.15 formal real-execution freeze

P3J.15 is the first user-executable P3J protocol. The shared real-data loop now
constructs one common frozen initial decision target for all four matched
policies. PCPI initializes the complete four-power class-conditional state and
can reach the measured pool only through the identity-bound resumable P3J
transaction. The three baselines continue through the established shared
policy implementation.

The byte-frozen configuration authorizes exactly the registered three real
targets, eight seeds, 32 initial observations split 16/16, 32 acquisitions,
128 candidates, 256 validation observations, four ambiguity powers, and the
32--512 adaptive quadrature schedule. Validation remains post-ledger and
held-out remains closed.

The Windows supervisor freezes branch, commit, tree, config, Python executable,
and runtime identities; isolates the historical untracked evidence directory;
runs a hidden child process; streams both outer progress and P3J quadrature
checkpoints; and validates the terminal summary, manifest, evidence registry,
and held-out flags. A process interruption may resume the same nonterminal
workspace. Published policy failures, completed runs, source changes, or
configuration changes cannot resume or overwrite.

The gate itself reads no registered data and runs no efficacy experiment. The
single formal command is executed only by the user after the committed source
and output identity are frozen.
