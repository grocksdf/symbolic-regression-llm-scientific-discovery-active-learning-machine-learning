# Complete structural-plan Bayesian selection

The opt-in `structural_plan_pool` and `predictive_plan_policy` modules connect
real ProposalRuntime batches and deterministic program proposals to the same
immutable complete-equation pool. Source labels, task names, and LLM self-ratings
are excluded from the eight behavior features. AST remains a representation and
size descriptor, not the sole context. Complete LLM equations do not receive an
invented subtree attribution.

The benchmark adapter is `scripts/predictive_plan_search.py`. It compares random
and Thompson selection from the identical frozen pool with two evaluation slots
per block and isolated policies. Exhaustion is recorded; no replacement proposal
is requested. Provider attempts and shared proposal costs are preserved.

The reward remains the existing two-fold E0/candidate predictive-stacking
increment. It already measures complementary mixture prediction, rather than
standalone fit error. It is a one-candidate search surrogate, not the eventual
multi-candidate independently admitted Bank utility. One pair contributes one
averaged difference. Shared adaptive folds imply a conditional working Bayesian
regression, not calibrated scientific uncertainty or a causal guarantee.

Explicit formula undefinedness and core duplicates execute KEEP_E0 (zero
expansion value). Negative valid rewards remain negative. Both-fallback pairs
and identical feature differences are logged without posterior updates. Unknown
numeric, optimizer, infrastructure and provider errors remain terminal failures.

All generation artifacts freeze before independent calibration, admission and
reporting readers open. These readers never train selection. The reference
statistical core and historical runners are unchanged. Frontier is off.

Frozen transfer priors require task-disjoint hashed observations and complete
posterior reconstruction. Production use still requires a new reviewed freeze;
these modules neither authorize an experiment nor demonstrate improvement.

Correctness checks cover conjugate batch equivalence, atomic updates, failure
classification, immutable features, transfer isolation, genuine typed-response
adaptation, shared pools, signed rewards and reporting/admission isolation.

References: [Thompson sampling tutorial](https://arxiv.org/abs/1707.02038),
[predictive stacking](https://arxiv.org/abs/1704.02030).
