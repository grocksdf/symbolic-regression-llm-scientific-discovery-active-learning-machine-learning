# Typed Scientist independent-confirmation contract

The primary endpoint is lexicographic and remains defined when an ablation
collapses:

1. the full system must retain an operationally viable bank;
2. the typed LLM source must be admitted with every fold gain above its
   numerical tolerance;
3. a no-LLM collapse counts as a control failure, not as an excluded task;
4. when both systems remain viable, full must have a strictly positive paired
   proper-log-score gain beyond numerical tolerance.

This endpoint was frozen after the Gas-NOX development case and before any
independent confirmation. It does not use an observed entropy threshold.

All CCPP, Airfoil and Gas coordinates used during method development are
ineligible for confirmation. The available NIST ASD alkali-ns family is also
currently ineligible because its reciprocal and shifted-power physics is not
representable by the frozen closed basis. Expanding the grammar and then
calling the same task a confirmation would change the method.

Consequently no current real execution is authorized. Confirmation remains
blocked until an untouched real-data family compatible with the frozen method
is registered, or until a new method is developed and evaluated under a new
claim rather than this confirmation contract.
