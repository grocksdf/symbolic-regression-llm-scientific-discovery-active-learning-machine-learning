# Expanded Full decision gate: common H0 classes and independent selector data

Status: **response-free source composition only**. Based on `main` at
`6a7679c`. No prior confirmation result is changed; no measured executor or
real experiment is authorized by this record.

## Corrected evidence flow

The candidate is chosen using `gap_admission`. Its fixed-expert regional
selector is now updated with a separate `decision_selector_update` validation
role. `decision_calibration` supplies the caller's finite-law provenance and
must be disjoint from every fitting, gap, admission and selector role. An
identical covariate row with a different response is also treated as overlap.
The action audit records both role identities and retains signed effects,
including negative ones. A calibration fingerprint establishes separation;
it does **not** prove that the caller's law family was fitted or calibrated
correctly, or that it covers a continuous real response law.

The optional-candidate attempt ceiling is frozen from the typed-synthesis and
inner-proposal reserves times the cycle count. Exceeding it fails before
opening candidate-admission responses. This is a source-budget check, not a
matched-compute Full/No-LLM experiment: Full still gets provider and extra
evaluation work under the quality-first exploration contract.

## Common class coordinates

The expanded bank freezes its operational classes once on development H0,
using its complete support, shared action domain, shared mixture scale and
registered budget resolution. `freeze_common_class_projection` maps every
protected core structure ID into those **same** classes. The core posterior
has exactly zero mass in classes with no core structure, rather than
reclustering or renaming the classes. It rejects crossed H0, action domains,
budgets, missing core supports and posterior/bank identities. The immutable
projection hash is included in `QUALITY_FIRST_EXPANDED_BANKS.json`.

This is a coherent common *label space* for a prospective 0-1 class loss,
conditional on the frozen expanded support and H0. It is not an independent
scientific truth label. The two banks still have distinct priors and
posteriors, and the preexisting bank-local risk trajectories must not be
subtracted as if they were a measured common-target decision effect. The
projection is response-free and `common_class_loss_assessed=False` remains
intentional until a shared loss calculation and selection lifecycle are
actually composed and audited. Since the class map is frozen using the Full
bank, it must be fixed **before** either arm reads action or reporting
responses; it may never be regenerated after seeing outcomes.

`finite_law_common_class_action_audit` provides a narrower reference: given
one externally specified union class and finite action-response law, it
updates both original PCPI posteriors at each response node and evaluates
both MAP decisions under the same zero-one class loss. It retains either sign
of the difference. The synthetic correctness fixture exhibits both positive
and negative effects by changing the stipulated true class. It does not infer
that class from independent real data, select a measured action, or certify a
continuous response integral; its authorization flags remain false.

## Remaining serial gates

1. Register the union-label class decision, action and reporting estimands,
   fixed reference action and loss in an actual sequential policy. Check the
   same projection after every posterior prefix. The finite node calculation
   above is one conditional same-loss reference, while the older regional
   finite-law squared predictive-mean loss is a different target.
2. Build and independently audit a plausible continuous response-law family.
   The present finite response nodes plus caller-supplied probabilities have
   no empirical coverage or continuous quadrature bound. Keep signed
   candidate action effects for all calibrated laws, including failures.
3. Supply outward numerical bounds for **the whole** prospective ranking,
   including predictive density, selector update, response integration and
   class risk. An interval that only bounds a finite-law diagnostic cannot
   authorize an action under the measured PCPI objective.
4. Reserve independent reporting responses outside all discovery, admission,
   selector, calibration and action roles. Commit action plans before reveal;
   admit each selected response exactly once; on replay verify every prefix,
   bank, class map, target, budget, source and numerical control identity.
   Existing optional independent predictive reporting is a useful diagnostic
   but is not this transaction gate.
5. Run response-free exact-reference and fault-injection checks for the
   integrated runner. Freeze a new user-executed development protocol before
   any real outcome is opened. The old measured executor continues to reject
   expanded exploration banks; do not remove that block as a shortcut.

The correctness fixtures for the current patch exercise the independent role
boundary, reused covariates with changed responses, exceeded candidate
budget, fixed union labels, zero core support in additional classes, and
crossed-bank rejection. They do not test Full > No-LLM efficacy.
